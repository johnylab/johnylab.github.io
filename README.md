# johnylab.github.io

Site e blog de João Ferreira: [johnylab.com.br](https://johnylab.com.br). Jekyll hospedado no GitHub Pages, home bilíngue (EN `/` e PT-BR `/pt/`) e blog em português.

- Textos da home: `_data/i18n.yml` (editar as duas línguas). Contato e redes: `_data/vcard.yml`.
- Posts: `_posts/AAAA-MM-DD-slug.md`.
- Instruções para sessões de IA: [`CLAUDE.md`](CLAUDE.md).

```
bundle install
bundle exec jekyll serve
```
